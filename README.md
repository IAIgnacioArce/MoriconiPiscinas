# 🏊‍♂️ Moriconi Piscinas - Landing Page Premium

Sitio web oficial para **Moriconi Piscinas**, empresa con más de 55 años de trayectoria en la construcción de piletas en Córdoba, Argentina. 

Este proyecto fue desarrollado con un enfoque arquitectónico y minimalista, priorizando la solidez visual, el rendimiento y una experiencia de usuario inmersiva a través de microinteracciones avanzadas.

🔗 **[Ver la página en vivo](https://moriconi-piscinas.vercel.app/)** 

---

## ✨ Características Principales

* **🌊 Simulación Física de Agua:** Implementación de un efecto *Ripple* interactivo mediante WebGL en la sección principal, permitiendo que el fondo reaccione al cursor del usuario simulando la física de los fluidos.
* **📐 Diseño Arquitectónico:** UI estructurada con CSS Grid y Flexbox, líneas crudas, tipografía nativa para carga instantánea y una paleta de alto contraste.
* **📱 100% Responsivo:** Adaptación perfecta a cualquier tamaño de pantalla (Mobile, Tablet, Desktop).
* **🚀 Optimización SEO y Semántica:** Estructurado con etiquetas HTML5 semánticas (`<header>`, `<section>`, `<article>`, `<footer>`) para un mejor posicionamiento en buscadores.
* **💬 Integración con WhatsApp:** Botones flotantes y llamados a la acción (CTAs) con mensajes preconfigurados para facilitar la conversión de clientes.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Estilos puros, variables nativas (`:root`), Grid layout y transiciones fluidas. Ningún framework externo para mantener la ligereza.
* **JavaScript:** Lógica de interacción.
* **jQuery & Ripples Plugin:** Motor matemático para la simulación de las ondas de agua.
* **Vercel:** Despliegue continuo (CI/CD) e integración directa con GitHub.
